# Contributing

Thank you for considering contributing to RamShield!

We welcome all contributions: bug reports, feature ideas, documentation fixes, and code.

## Reporting Bugs

Please open an issue with:

- A clear title
- Steps to reproduce
- Expected vs actual behavior
- System info (OS, Rust version, RamShield version)

## Feature Requests

Open an issue with a concise description of the desired behavior.

## Code Contributions

1. Fork the repo
2. Create your feature branch (`git checkout -b feature/my-awesome-thing`)
3. Commit your changes (`git commit -m 'Add my awesome thing'`)
4. Push to the branch (`git push origin feature/my-awesome-thing`)
5. Open a new Pull Request

We use `cargo fmt`, `cargo clippy`, and `cargo test` as gate checks. Please run them locally.
